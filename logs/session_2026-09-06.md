# Session 2026-09-06

## Objective

Decide whether to continue repairing the unsupported 2021 XGO-Mini STM32/K210 electronics or move to a supported retrofit while preserving the original chassis and 12 servos.

## Vendor correspondence outcome

Pengfei (Bency) Liu / Luwu Dynamics confirmed that official support for the original first-generation K210 + STM32 V2.5 controller is discontinued.

They offered a supported retrofit package:

- ESP32-based replacement driver board;
- compatible battery kit;
- shipping to Hungary included;
- total price: **USD 75**.

The most important confirmation is that this ESP32 replacement is specifically adapted to work with the **original XGO-Mini chassis and all 12 original servos**.

## Confirmed technical details from vendor

The replacement ESP32 board:

- is a newer adapted revision, not the old STM32 V2.5 board;
- uses the standardized XGO serial command protocol;
- supports the core command set used by `xgolib`;
- supports normal locomotion, pose adjustment and kinematics calls via Python;
- exposes an external **3.3 V TTL UART** for Raspberry Pi / SBC / PC;
- UART signals are TX/RX/GND;
- can connect directly to Raspberry Pi GPIO without a level shifter;
- will be shipped with / accompanied by the exact firmware version/model profile and command mapping required for initialization.

Vendor will not provide the legacy servo-bus protocol, old board schematic or complete legacy hardware documentation.

## Current-generation parts compatibility

Vendor stated that latest Lite3 / CM5 AI modules and modular robotic arms are not direct plug-and-play parts for the original chassis because newer generations have different mounting, structural cable routing and integration.

Interpretation:

- do not attempt to turn the old robot into a literal Lite3/mini2 by buying a full current-generation head/arm stack;
- use the ESP32 replacement only as the supported low-level motion layer;
- build a custom upper compute/HMI layer as secondary development.

## Chosen project direction

Preferred architecture is now:

```text
original aluminum chassis
+ original 12 servos
+ vendor ESP32 motion board
+ custom Raspberry Pi/CM/SBC upper layer
+ inexpensive display
+ modern camera
+ network connection to PC / Local GPU Helper
```

The old K210 display/camera is no longer a required dependency. It may be kept only if useful as a temporary/legacy component.

## Cost rationale

The original XGO-Mini was backed on Kickstarter in 2021 for approximately USD 624 total including shipping.

The objective is not to obtain a current USD 1000+ robot cheaply. The objective is to reuse the already-owned high-value mechanics/servos and spend only enough to obtain a current, supported motion controller.

A USD 75 supported ESP32 board+battery retrofit is considered reasonable if it restores reliable motion and gives a documented serial interface.

## Battery note

The original robot uses removable 18650 cells. It may be possible to source suitable cells locally more cheaply, but this should only be done if the new retrofit board's exact battery/BMS/connector requirements are confirmed.
