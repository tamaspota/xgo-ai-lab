## Upstream research

Reviewed `LuwuDynamics/xgo_doglib` on 2026-09-03.

Relevant facts from reviewed source commit `cf72514273dc703284d3c47e46c67ce238caae11`:

- `XGO()` supports `xgomini`.
- default serial baud is 115200.
- firmware version address is `0x07`.
- upstream `read_firmware()` requests 10 bytes using read mode `0x02`.
- the corresponding raw request is `55 00 09 02 07 0A E3 00 AA`.
- current `XGO_DOG.__init__` performs `reset()` and reads yaw during initialization.

Consequence: continue avoiding the current high-level library during initial hardware bring-up. The local raw probe sends only the inspected firmware READ request.

Silicon Labs documentation confirms that CP210x devices require a **Virtual COM Port (VCP) driver** to appear to host applications as a COM port. The driver is now installed and the interface is working as COM3.
