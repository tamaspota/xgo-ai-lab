## Upstream research

Reviewed `LuwuDynamics/xgo_doglib` on 2026-09-03.

Relevant facts from reviewed source commit `cf72514273dc703284d3c47e46c67ce238caae11`:

- `XGO()` supports `xgomini`.
- default serial baud is 115200.
- current `XGO_DOG.__init__` performs `reset()` and reads yaw during initialization.

Consequence: do not use the current high-level library for the first hardware discovery pass because initialization is not passive.
