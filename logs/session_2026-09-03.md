## Historical built-in self-test discovered

Reviewed historical `sd/main.py` and `sd/device_test.py`.

`main.py` enters factory/general test mode when the **left/A button is held during boot** while the right/B button is not held. It executes:

`/sd/device_test.py`

The historical test sequence checks:

1. LCD RGB
2. camera
3. microphone / FFT
4. SD card
5. speaker
6. A/B/C buttons
7. LEDs

The SD stage calls `os.listdir("/sd")` and reports success only if `try_demo.py` is found.

Consequence: the next lowest-risk step is to run this built-in test. It can answer whether the advertised SD card is installed/mounted and whether the expected application tree is present **without opening the robot or reflashing anything**.

Detailed instructions added at `docs/FACTORY_SELF_TEST.md`.
