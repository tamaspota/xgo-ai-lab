## Key evidence

### Original hardware generation

Period product documentation specifies:

- processor: K210 + STM32;
- K210 as AI/high-level module;
- STM32 as the core motion controller;
- LCD: 240 x 240;
- camera: OV2640, 0.3 MP;
- storage: 16 GB SD;
- battery: 7.4 V 2500 mAh.

### Original direct control interface

XGO-Mini Communication Protocol V1.0 specifies:

- XH2.54 4-pin TTL serial;
- 115200 baud, 8N1;
- two core-board UART terminals;
- 3.3 V terminal occupied by the AI module by default;
- unplug AI-module terminal for direct external control.

### Current firmware mismatch risk

Current XGO-Mini documentation publishes lower-board firmware for ESP32-based generations. That must not be assumed compatible with the 2021 STM32 core board even though both are called XGO-Mini / M-series.
